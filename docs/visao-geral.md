# Visão geral

## 1. Objetivo

Criar a identidade visual e o site da RA, com tecnologias atuais e estáveis e
documentação desde o início. *Definido pelo dono (2026-11-18).*

## 2. O que este documento ainda não sabe

Nenhuma informação sobre a RA foi registrada além do nome do repositório. Este
projeto não presume a atividade, o público nem o conteúdo: tudo isso depende das
respostas abaixo.
